\chapter{Système de fichiers centralisé — DFS}

\section{Architecture}

Le serveur de fichiers \texttt{srv-fichiers01} héberge les partages physiques SMB. DFS fournit une \textit{couche logique} transparente (\texttt{\\corpmsi.local\Partages}) qui masque la complexité des serveurs physiques.

\begin{lstlisting}

  → Manage
    → Add Roles and Features
      → Server Roles
        → File and Storage Services
          → File and iSCSI Services
            → DFS Namespaces
\end{lstlisting}

\begin{lstlisting}
Server Manager → Tools → DFS Management
  → Right-click Namespaces
    → New Namespace

Server        : srv-dc01

\end{lstlisting}

\section{Lier les dossiers DFS}

Pour chaque dossier DFS, ajouter une cible physique :

\begin{lstlisting}
DFS Management
  → Namespaces
    → \\corpmsi.local\Partages
      → Right-click Direction
        → Add Folder Target

Server     : srv-fichiers01
Share      : DIRECTION$
\end{lstlisting}

\section{Énumération basée sur l'accès}

\begin{lstlisting}
\\corpmsi.local\Partages
  → Right-click
    → Properties
      → Advanced tab
        → [X] Enable access-based enumeration
\end{lstlisting}

Avec ABE activé, les utilisateurs voient uniquement les partages auxquels ils ont accès.

\section{Permissions NTFS}

Configurer les permissions NTFS sur chaque partage physique :

\begin{lstlisting}[style=powershell]
# Exemple : partage DIRECTION
$path = "E:\Partages\DIRECTION"
$group = "corpmsi\GRP_Direction"

# Donner accès au groupe
$acl = Get-Acl $path
$rule = New-Object System.Security.AccessControl.FileSystemAccessRule(
    $group, "Modify", "ContainerInherit,ObjectInherit", "None", "Allow"
)
$acl.AddAccessRule($rule)
Set-Acl $path $acl
\end{lstlisting}

\section{Vérification}

Depuis un poste client (ex : PC-BUR01 sur VLAN 10 Direction) :

\begin{lstlisting}[style=powershell]
# Voir les partages DFS
net view \\corpmsi.local\Partages

# Accéder au partage
net use Z: \\corpmsi.local\Partages\Direction

# Vérifier le serveur physique
Get-SmbConnection | Select-Object ServerName, ShareName
\end{lstlisting}

\section{Avantages DFS}

\begin{itemize}
    \item \textbf{Transparence} : Les utilisateurs ne connaissent pas le serveur physique
    \item \textbf{Failover} : Si srv-fichiers01 tombe, ajouter une 2e cible (redondance)
    \item \textbf{Équilibrage} : Les cibles multiples équilibrent la charge
    \item \textbf{Migration} : Changer le serveur physique sans impacter les utilisateurs
\end{itemize}
