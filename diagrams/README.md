# Diagrammes d'architecture

Ce dossier contient les schémas de l'infrastructure corpmsi.

## Fichiers

- **ad_corpmsi.drawio** — Diagramme complet en format draw.io (éditable)
- **ad_corpmsi.png** — Export PNG du diagramme (aperçu rapide)

## Affichage

### Fichier .drawio

Ouvrez dans l'une de ces applications :

- [draw.io](https://draw.io) (en ligne, gratuit)
- [VS Code extension](https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio) (dans l'éditeur)
- [LibreOffice Draw](https://www.libreoffice.org/) (local)

### Fichier .png

Visualisez directement dans n'importe quel visionneur d'images.

## Contenu du schéma

Le diagramme illustre :

- ✅ Topologie réseau complète avec 6 VLANs
- ✅ Placement des serveurs (DC, NAS, pfSense)
- ✅ Flux de trafic inter-VLAN
- ✅ Positions des pare-feu et points de filtrage
- ✅ Connexions Internet et services externes
- ✅ Représentation des postes clients par département
